# Desktop and VR modes

The header mode switch selects Desktop or VR presentation. Desktop exposes mouse CAD controls with a voice/text composer; immersive entry is available only in VR mode. Switching saves the current session and reuses the same browser store and session ID, including geometry, origins/placements, drawings, audio assets, history and unsent text. Legacy Desktop and VR stores are preserved: the validated `projectStore` URL value selects the originating store rather than copying large recordings or opening an unrelated active project. Both modes use the same backend.

Desktop places Enable microphone, microphone status/level, instructions and Send at the top of the sidebar. Clicking Enable microphone requests browser permission. Previously enabled capture resumes once permission is granted, including after mode changes; Stop microphone disables this preference. Typed Send works independently of microphone availability and automatic sketch refinement. Ctrl/Cmd+Enter sends; ordinary Enter inserts a newline. Audio segments are sent with current scene evidence using the existing audio pipeline. Microphone capture requires localhost or HTTPS when hosted remotely.

A mode change waits for ongoing speech/editing to finish or be stopped, finishes active ink, ends an immersive session if present, saves pending microphone assets and the session, and releases the old writer before loading the other presentation. It does not convert geometry or change its frame.
