# Drawing and CAD editing layers

The desktop toolbar exposes Drawing / CAD modes and an Eraser (E). This is a sketch editing layer, separate from the Desktop / VR switch and Advanced CAD workspace.

Drawing mode now erases only brush-covered portions of raw ink, including between sparse samples. It interpolates original XYZ points/times at cut boundaries, retains disconnected remainders with erasure lineage, and supports one-step undo/redo for each gesture. Erased siblings are not rejoined across the cut, and automatic fitting preserves intentionally opened paths. A stroke selected in the target menu/cursor scopes the edit to that drawing; other unchanged same-plane previews are retained as references. CAD mode trims only the curve/line portion under the screen-space brush. Dragging previews the surviving pieces immediately, then commits on release. Lines and circles retain analytic line/arc geometry; cubic spline remainders are exact de Casteljau subcurves. Cuts open closed profiles rather than silently reconnecting endpoints. A selected CAD target restricts erasure to it; with no target, all touched sketch figures can be trimmed. Native primitive creation tools and vertex/edge dragging operate in CAD mode; the pen remains available in both layers.

CAD trim is a validated native transaction: delete affected objects, publish retained pieces as editable objects, then update canonical figure state. The first retained piece keeps the original figure ID, additional pieces get new IDs, and complete erasure removes the object. Failed native application restores the prior document and figures. Topology-changing cuts release affected symmetry/coincidence links, with history preserving the original metadata. Raw erasure supports stroke undo; native cuts support History restore. Sketches supporting an extrusion or multi-sketch solid must have that dependent feature removed/edited before their boundary can be opened.

The target selector names the drawing being edited. Clicking a raw stroke chooses its drawing plane and highlights it; selecting a CAD figure carries its exact ID/version, numerical geometry, selected component and reference image into model context. The Decisions route can choose add-detail / independent / replacement of a complete selected outline. Replacement updates the same native figure, with bounds/plane/version checks and a single Accept; it does not duplicate the target. Partial details remain additions. The regular desktop route receives the same edit context and uses explicit element-edit instructions for selected CAD corrections. Switching back to Drawing clears the CAD replacement target so a new part does not inherit it accidentally.

Intentional erasure is recorded in editContext.lastErasure, with affected stroke/figure/sketch IDs. The model is prompted to preserve those openings rather than treating them as pen gaps. Undo invalidates the operation context when the prior geometry is restored. Erasing raw ink invalidates an in-flight preview; CAD mutations wait for pending AI previews to be accepted/discarded.
