# Multi-plane sketch matching and direct editing

The Decisions experiment now keeps accepted geometry and unchanged previews on other planes as references. It classifies the active/new strokes, rather than reinterpreting older views on every turn. Retained previews use a muted color; the current output stays mint. Cached geometry is invalidated by changed/deleted source ink, returning to that plane for editing, or explicit discard/incorrect feedback. The last recorded case hydrates the cache after reload. Only Accept publishes the combined staged geometry.

Model input includes original plane frames, world-coordinate extents, bounded sampled reference paths rendered in their ORIGINAL sketch planes, and numerical correspondence candidates. Reference images must not be rendered in a fitted symmetry frame: that can rotate the view and confuse correspondence. The Decisions API selects common extent or feature-level alignment, or independence. Shared directions come from the plane normals; parallel offset planes have two shared directions. Numerical fitting preserves the sketch plane and intrinsic primitives. Existing reference geometry never moves in response to a new stroke. The same mechanism proposes nearby corner/edge coincidence and shared U/V levels for open stroke endpoints. Geometric correction budgets reject attachments that excessively distort the outline; exact user offsets and separate parts remain possible.

Click a fundamental plane button, or choose a plane in the scene, then use New plane. Choose XY/XZ/YZ or another base plane, one normal offset in millimetres, and X/Y tilts in degrees. The preview updates before creation. Offset is applied along the base normal; rotation order is local X then the resulting local Y, pivoting at the new origin. Saved planes remain clickable and usable as sketch supports. Existing offset/drag, attached sketch movement, history and loft behavior remain.

Double-click the canvas to switch pen/cursor. In cursor mode, click/drag accepted sketch vertices or edges. The constraints panel exposes new-sketch symmetry and H/V preferences, plus selected-figure mirror/alignment rules; dashed lines show the mirror axes. Curve/line profile edits use least-squares projection with exact symmetry and alignment constraints. An edge crossing a mirror axis moves in its feasible direction, with the opposite edge following. Rectangle/circle handles preserve their analytic type. Editing a reference propagates to connected downstream endpoints. Alt-drag detaches outgoing connections. Existing point-on-edge links follow the moved edge; shared-coordinate links preserve only that coordinate. Fixed outgoing coincidence can block an endpoint drag; move its reference or detach. This is a directed sketch constraint graph, not a complete SolidWorks assembly solver. Analytic arcs/ellipses still use their dimension controls.

Component edits are validated before native mutation, committed as a batch, and restored if native application fails. History now includes constraint metadata, so restoration preserves the same rules. The browser editor shows a temporary drag preview and commits on release; no provider call occurs for a manual edit. Camera/mode/figure changes invalidate its visual cache, avoiding repeated idle geometry rebuilds.
